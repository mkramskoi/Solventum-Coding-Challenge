# Solventum-Coding-Challenge
Solventum Coding Challenge

Start application.
Example of usage:

To shorten url
http://localhost:8080/encode?url=https://aws.amazon.com/connect/?trk=b2cc5159-9de2-4d31-97d8-b307ff66e724
Response:
{"url":"https://www.att.com","shortUrl":"http://short.est/3sD4Bw8-Wi"}

To decode short url back to the long one:
http://localhost:8080/decode?url=http://short.est/4KMg1XrWyA
Response:
{"url":"http://aws.amazon.com/connect/?trk=b2cc5159-9de2-4d31-97d8-b307ff66e724","shortUrl":"http://short.est/4KMg1XrWyA"}
